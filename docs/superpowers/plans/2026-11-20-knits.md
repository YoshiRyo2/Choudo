# Hoodies / sweaters (PR 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `knit` template (hoodie, sweatshirt, sweater, cardigan) fitted on chest, length, sleeve and rib hem band, with a `weight` field, a knit drawing on the tee template, data checks, and two real garments.

**Architecture:** Knits are data in the existing registry (`categories.ts`, `zones.ts`, `rules.ts`), as pants were. Centre-back length and sleeve are scored by working out the body target from existing body keys (`domain/fit/tops.ts`), so no new body keys and no sampler change. The drawing stays `topShape`, which reads the same `tops.ts` conversions plus knit details (rib hem from the chart's hem band, cuffs, hood).

**Tech Stack:** TypeScript, Vitest, React SVG (no new dependencies).

**Spec:** `docs/clothing-categories-design.md` §6 "PR 2 — hoodies / sweaters", plus the user's brief (in the PR body).

## Global Constraints

- New thresholds are labelled **ASSUMED** in their doc comment, with the reasoning.
- Every existing garment's golden lines (`src/domain/fit/__golden__/*`) stay byte-identical; the new garments only add lines.
- Skin rule: every length, height and girth the drawing uses comes from `domain/` (body model, garment chart, or a `domain/fit` function). Rib, cuff and hood shapes are surface only.
- New measurement keys go at the end of `MEASUREMENT_KEYS`.
- Seed values copied as printed; anything not on the chart is `{ value, origin: "estimated", how }`.
- `npm run check` exits 0 before every commit.

## Review Focus

1. A tee whose chart says `center_back` length must still be "unknown" (tees accept only `hps`); only knits accept centre-back definitions.
2. A knit without a hem band (the Comfort Colors chart has none) must not turn the size "unknown": the hem band zone is optional.
3. A knit must not be offered as an anchor ("a tee you like"): its chest carries the knit offset.
4. `bodyAt` on existing pants waists must still be `"band"` (golden), and a centre-back zone must not say "where the waistband sits".
5. A hoodie sleeve longer than the arm must not draw past `arm.len × 1.06`; a cuff never narrower than the wrist.

### Task 2: Fit — knit zones, centre-back targets, hem band, knit offset

**Files:** Create `src/domain/fit/tops.ts` (+ `tops.test.ts`). Modify `rules.ts`, `zones.ts`, `fitEngine.ts` (`bodyAt` from spec), `preference.ts`, `index.ts`. Tests: `zones.test.ts`, `preference.test.ts`, `fitEngine.test.ts`.

**Interfaces — produces:**
- `rules.ts`: `BACK_NECK_DROP_CM = 2` (ASSUMED: typical back-neck drop, HPS length − CB length); `KNIT_EASE_OFFSET_CM = 10` (ASSUMED: Gildan grades its 18500 hoodie 4 in fuller per size than its 5000 tee); `KNIT_GIRTH_RULES: Record<GarmentSizing, GirthRule>` = the top chest rule with `fittedMax`, `relaxedMax`, `ideal` + offset, `tightBelow` unchanged; `HEM_BAND: GirthRule` (ASSUMED) tightBelow −2, fittedMax 4, relaxedMax 12, ideal 0, vs hips.
- `tops.ts`: `lengthTargetCm(m, def)`: hps → torso, center_back → torso − drop; `sleeveTargetCm(m, def)`: shoulder_to_cuff → arm, center_back_to_cuff → arm + shoulderWidth / 2; `hpsLengthCm(garment, size): number | undefined`; `sleeveFromShoulderPointCm(garment, size, m): number | undefined`.
- `ZoneSpec.bodyAt?: 'band' | 'centre_back'` (pants waist sets `'band'`; fitEngine reads it when the target is worked out). `ZoneFit.bodyAt` widens to match.
- `TEMPLATE_ZONES.knit`: chest (bySizing knit rule), length (needs hps | center_back, `bodyTarget` by definition, bodyAt centre_back), sleeve (long only, needs shoulder_to_cuff | center_back_to_cuff), hemBand (bodyKey `hipsCm`, optional). `personal: { girth: 'chest', length: 'length', easeOffsetCm: KNIT_EASE_OFFSET_CM }`.
- `chestTarget(pref, intent, offsetCm = 0)` adds the offset to both targets; `canAnchor` false for a template with an offset.

- [ ] Failing tests: tops.ts targets (176/85 mens: CB sleeve = arm + shoulder/2); knit CB length scores against torso − 2 with `bodyAt: 'centre_back'`; tee with `center_back` length still unknown; knit without hemBand → overall not unknown; hem band 'tight' only below −2 − 0.2 × hips with `high` stretch; personal chest miss on a knit uses +10 offset; `canAnchor(knit) === false`.
- [ ] Run, fail; implement; pass; golden unchanged; commit.
