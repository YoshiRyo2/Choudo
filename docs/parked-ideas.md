# Parked ideas

Ideas we've decided not to build yet, with any rule that still holds while they wait.

## Mannequin style

Mannequin style is parked. Hard rule for any style: style the surface
(head, colours, materials, motion), never the body proportions. Shoulders,
chest, waist, legs and height must stay exactly as the fit engine computes
them. Body geometry and garment fitting stay separate from how the
mannequin is drawn, so a style is only a rendering skin.

See also [clothing-categories-design.md](clothing-categories-design.md), which applies the same rule to new
garment categories ("body proportions come only from the fit engine; drawing is a skin on top").
